PHP CRUD Application

A simple Create, Read, Update, Delete (CRUD) application built with PHP, featuring:
Form validation
Search functionality
Pagination for listing records
Image upload & image preview  
Clean and organized code structure

🚀 Features

Add new records with server-side validation
Edit and update existing records
Delete records safely
Search records by keyword
Paginated listing for easy navigation
Upload and view images for each record  
Lightweight and easy to customize

🛠️ Technologies Used

PHP (Core PHP, no frameworks required)
MySQL
HTML / CSS

📦 Installation & Setup

Clone or download the project:
git clone https://github.com/jyotithakur144/Php-Crud-Application

Import the SQL file into your database:
Create a database (e.g., crud_db)

Import database.sql
Update database configuration in the project:

// config.php
$conn = mysqli_connect("localhost", "root", "", "crud_db");

Ensure uploads folder exists

Create a folder:
/uploads


Run the project in your browser:

http://localhost/Php-Crud-Application/
